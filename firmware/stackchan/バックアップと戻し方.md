# Stack-chan のバックアップと戻し方

確認用の Arduino スケッチ（`arduino/obake_pahub_bringup`）を書くと、**今入っている会話ファームは消える**。  
戻す手段は、書く **前** に取った Flash の丸ごとコピーだけ。

この PC で一度成功した実体:

| 項目 | 値 |
|------|-----|
| ポート | **COM3**（変わることがある。毎回確認） |
| バックアップ | `C:\Users\kazuh\Documents\stackchan_backup\stackchan_backup.bin` |
| サイズ | **16,777,216 バイト（16 MB）** ちょうどなら成功 |
| ボード | M5Stack CoreS3（ESP32-S3） |

Arduino IDE のシリアルモニタは、バックアップ／戻しのあいだ **閉じる**。

GUI でやる場合: [tools/obake_flash_gui.pyw](tools/obake_flash_gui.pyw) をダブルクリック。  
バックアップ bin の選択・おばけちゃん FW（IDF `build`）の選択・16 MB 読み取りができる。

---

## 準備

- USB-C は **データ通信**用。充電専用だと COM が出ない。
- CoreS3 本体下の USB-C へ。
- PowerShell:

```powershell
python --version
pip install esptool
python -m esptool version
```

COM 番号: Arduino IDE → ツール → ポート、またはデバイスマネージャー → ポート (COM と LPT)。  
ケーブルを抜くと消える番号が Stack-chan。以前は COM3。

作業フォルダ:

```powershell
mkdir $env:USERPROFILE\Documents\stackchan_backup
cd $env:USERPROFILE\Documents\stackchan_backup
```

---

## バックアップの取り方（確認用を書く前）

```powershell
cd $env:USERPROFILE\Documents\stackchan_backup
python -m esptool --chip esp32s3 -p COM3 -b 921600 read_flash 0 0x1000000 stackchan_backup.bin
```

- 数分かかる。止めない。
- エクスプローラーでサイズを見る。**約 16.0 MB（16,777,216 バイト）** なら成功。
- 0 バイトや数 KB なら失敗。次へ進まない。USB や別フォルダにもコピーすると安心。

失敗するとき:

1. Arduino のシリアルモニタを閉じる
2. ケーブルを挿し直す
3. ダウンロードモード: 本体下の **RST を約 3 秒長押し** → 緑 LED が点いたら離す
4. 遅めにする:

```powershell
python -m esptool --chip esp32s3 -p COM3 -b 115200 read_flash 0 0x1000000 stackchan_backup.bin
```

**16 MB の bin ができるまで、Arduino の書き込みはしない。**

---

## 戻し方（確認が終わったら）

Arduino の「書き込む」では戻らない。esptool で bin を書き戻す。

```powershell
cd $env:USERPROFILE\Documents\stackchan_backup
python -m esptool --chip esp32s3 -p COM3 -b 921600 write_flash 0 stackchan_backup.bin
```

終わるまで 1〜2 分。`Hash of data verified` が出れば成功。自動でリセットされる。いつもの Stack-chan（Xiaozhi）の画面になる。

失敗するときはバックアップと同じ（モニタを閉じる、RST 長押し、baud 115200）。

bin が無い／壊れているときは、この PC に Stack-chan のソースが無いので戻せない。別 PC の `idf.py flash` か、別途取った bin が必要。

## 本番ファーム（ESP-IDF）の書き込み

Arduino 確認用ではなく、**おばけ入り Stack-chan** を書くとき。

手順の正本は [引き継ぎ.md](引き継ぎ.md) の「ビルド／書き込み（手動・PowerShell）」。

要約:

```powershell
$env:IDF_TOOLS_PATH = "C:\Espressif\tools"
. "C:\Espressif\tools\Microsoft.v5.5.4.PowerShell_profile.ps1"
Set-Location "C:\Users\kazuh\Documents\Arduino\Obake_device\firmware"
idf.py build
idf.py -p COM3 flash
```

書き込み前にシリアルモニタを閉じる。ポート番号は毎回確認。

## 確認用スケッチを書くとき（参考）

順番だけ:

1. 上のバックアップが済んでいること
2. Arduino IDE で `arduino/obake_pahub_bringup/obake_pahub_bringup.ino` を開く
3. ボード: **M5CoreS3**（または M5Stack CoreS3）、ポート: いまの COM
4. 書き込む
5. 終わったらこの資料の「戻し方」

配線など確認用の詳細は [arduino/obake_pahub_bringup/FLASH.md](arduino/obake_pahub_bringup/FLASH.md)。

## やってはいけないこと

- バックアップ前にスケッチを書く
- 充電専用ケーブル
- 別機器の COM に書く
- 16 MB 未満の壊れた bin で戻したつもりになる
- `stackchan_backup.bin` を消す
