方針

チャットボットは答える。エージェントは動く。ただし道具に届き、隔離してコードを回し、取り返しのつかない操作の前に人が止められること。土台は TrueForge。

フォルダのフルアクセスは、TrueForge の隔離から外れてこの Mac でシェルを回す。ハーネスの強みの逆だったので、撮影デモからは外した。

失敗 方針

Mac Mini 賞の任意だと思っていた。公式ルールでは提出そのものの条件だった。実質的な変更は Qodo がレビューした GitHub PR を通す。main 直 push は数えない。

2026-08-29 14:01

Qodo が High を4つ出した

失敗 改善

レビューは動いた。指摘は妥当だった。撮影デモの外のオーバーレイが、ホストのシェルと API キーに届く形になっていた。

  • エージェント API は loopback のみ。撮影ジョブは grants を無視。フルアクセスは環境変数がないと拒否。
  • TrueForge の SSE delta を上書きせず連結。
  • OpenAI パスで兄弟ツールの応答が欠けないようにした。
  • フォルダ権限ではシェル禁止。子プロセスに秘密を渡さない。

Medium も直した。Allow 失敗で pending が消える、reset が誰でも全員分消せる、Electron が任意 URL で preload を渡す。

スレッドに返信し、同じ PR でフォローアップの /agentic_review を投げた。マージは再レビューのあと。
